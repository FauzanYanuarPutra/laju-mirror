This is a request for a policy review, not a request to disable Windows security controls.

Cargo reports:

~~~text
An Application Control policy has blocked this file. (os error 4551)
~~~ 

Blocked process examples from the development output:

- `src-tauri/target/debug/build/proc-macro2-*/build-script-build.exe`
- `src-tauri/target/debug/build/serde_core-*/build-script-build.exe`
- `src-tauri/target/debug/build/icu_normalizer_data-*/build-script-build.exe`

These are generated Rust dependency build-script executables. Cargo compiles and runs build scripts as part of the normal build process.

1. Review the attached LajuMirror Windows diagnostics report.

3. Review matching Code Integrity events, especially 3077 and correlated 3089 events, or the relevant AppLocker log entries.
