# Community Code of Conduct

LajuMirror aims to be a welcoming project for users and contributors with different backgrounds and experience levels.

We expect everyone participating in issues, discussions, reviews and contributions to:

- Be respectful, constructive and considerate.
- Give feedback about code and ideas, not personal traits.
- Welcome beginner questions and explain technical decisions clearly.
- Avoid harassment, insults, discrimination, threats and unwanted personal contact.
- Respect privacy. Do not publish someone else's device identifiers, contact details, private screenshots or other sensitive information.

Project maintainers may edit or remove abusive content and may restrict participation when necessary to protect the community.

For safety concerns, contact the repository maintainer privately through GitHub. See [SECURITY.md](SECURITY.md) for vulnerability reports.
